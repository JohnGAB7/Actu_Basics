Parcours Actuariat
==================

Le **Parcours Actuariat** couvre l'essentiel du metier d'actuaire en 11
modules (A0 a A9), avec des videos longues et des extraits verticaux
publies en francais et en anglais. Chaque module est accompagne d'une
fiche PDF resumee, et, lorsque c'est utile, d'un fichier tableur, R ou
Python pour refaire les calculs.

.. note::

   Les correspondances avec les examens professionnels (SOA, CAS,
   Institut canadien des actuaires, IFoA, formations francaises
   reconnues par l'Institut des actuaires) sont indiquees module par
   module. Formule employee : *Ce module aborde certaines notions
   evaluees dans les examens indiques ci-dessous. Il contribue a la
   preparation de ces examens, sans couvrir necessairement l'ensemble
   de leur programme.*
