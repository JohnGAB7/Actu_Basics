Format des fiches
=================

Chaque fiche contient :

- le titre de la lecon et son code ;
- les objectifs pedagogiques ;
- les formules et definitions essentielles ;
- un exemple corrige vérifiable ;
- les sources datees, lorsque la lecon s'appuie sur des chiffres reels ;
- les reperes de recouvrement avec les examens professionnels pour les
  lecons du parcours Actuariat.
