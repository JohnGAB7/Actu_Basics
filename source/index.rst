ACTU-BASICS
===========

**Eveiller par les chiffres** - *Enlightening through numbers*

Bienvenue sur le site de la chaine educative **ACTU-BASICS**. Les videos
YouTube longues et les extraits verticaux (TikTok, YouTube Shorts) sont
publies simultanement en francais et en anglais. Ce site regroupe le
parcours Actuariat, les lecons du Niveau 1 de statistiques et les fiches
telechargeables qui accompagnent chaque video.

.. grid:: 2
   :gutter: 3

   .. grid-item-card:: Parcours Actuariat
      :link: actuariat/index
      :link-type: doc

      De A0 a A9 : orientation, finance, probabilites, statistique,
      mortalite, assurance vie, non-vie, provisions, reassurance,
      solvabilite. Ouvrir le parcours.

   .. grid-item-card:: Niveau 1 - Statistiques
      :link: niveau1/index
      :link-type: doc

      23 lecons publiees. De la moyenne au test d'hypothese, en passant
      par les pourcentages, l'ecart-type et la correlation.

   .. grid-item-card:: Fiches telechargeables
      :link: fiches/index
      :link-type: doc

      PDF par lecon (FR et EN), fichiers tableur, R et Python pour
      refaire les exemples chez soi.

   .. grid-item-card:: References techniques
      :link: references/index
      :link-type: doc

      Python, R, SQL, SAS, MATLAB, Julia : memos et extraits de code
      utilises dans les lecons.
